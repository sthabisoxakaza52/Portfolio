# Sthabiso Xakaza — Portfolio

A personal portfolio website showcasing my journey as a software engineering student with a focus on cloud infrastructure and DevOps.

## About This Project

This portfolio is hand-crafted to tell my story — why I'm drawn to cloud engineering, what I've learned, and what I've built. It's intentionally simple: no frameworks, no bloat, just clean HTML, CSS, and JavaScript.

## What's Inside

- **About**: My background and why cloud infrastructure excites me
- **Learning Path**: Timeline of my technical journey from Python to AWS
- **Projects**: Real work I've done, from AWS cost monitoring to secure web apps
- **Skills**: What I know now and what I'm actively learning
- **Community**: Leadership roles and volunteer work beyond code

## Tech Stack

- HTML5
- CSS3 (Custom properties, CSS Grid, Flexbox)
- Vanilla JavaScript
- No build tools or frameworks

## Running Locally

Open `index.html` in any browser. That's it.

## Structure

```
Portfolio/
├── index.html        # Main page
├── styles.css        # All styling
├── script.js         # Interactivity
├── images/           # Profile photo and assets
└── README.md         # You're reading it
```

## Key Features

- Responsive design (mobile-friendly)
- Typing animation in hero section
- Smooth scroll and section highlighting
- Contact form with client-side validation
- Accessible keyboard navigation

## Customization

Colors are managed through CSS variables in `:root`. Change them in `styles.css`:

```css
:root {
    --color-primary: #f5b8c4;
    --color-bg-dark: #0f1419;
    /* etc. */
}
```
